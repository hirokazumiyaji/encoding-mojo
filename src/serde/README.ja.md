# `serde`

*[English](README.md) · 日本語*

このリポジトリのすべてのフォーマットが共有するドキュメントモデルです。

`Value` は `null`、真偽値、数値、文字列、シーケンス、マッピングのいずれか
— JSON、YAML、TOML、CSV が記述するものの共通部分です。フォーマットごとに 1 つ
ではなくモデルが 1 つだけなので、値は変換なしにフォーマットをまたげます。

```mojo
from json import dumps
from yaml import safe_load

print(dumps(safe_load("name: mojo\ntags: [fast, safe]\n")))
# {"name": "mojo", "tags": ["fast", "safe"]}
```

## テープ

値は個別に確保されたノードの木には置かれません。ドキュメント中のすべての値は、
3 本の配列からなる 1 つの平坦なアリーナ（"テープ"）に置かれます。

| 配列 | 保持するもの |
|------|-------------|
| `nodes` | 値 1 つあたり 24 バイトのレコード 1 件。種別タグと小さな共用体 |
| `kids` | コンテナの構成要素。配列なら要素インデックス、オブジェクトならキーと値のインデックスが交互に並ぶ |
| `buf` | すべての文字列のデコード済みバイト列を連結したもの |

したがって値が `n` 個のドキュメントの構築コストは `O(n)` ではなく `O(1)` 回の確保
で済み、`Value` は 12 バイトの参照カウント付きハンドル（テープとインデックス 1 つ）
になります。`Value` のコピーは参照カウントの加算であり、これが Python の参照
セマンティクスを与えます。`doc["a"]` は `doc` と記憶域を共有するので、片方を変更
すればもう片方も変わります。

メンバが 16 個を超えたオブジェクトにはハッシュ索引が付き、4 本目のアリーナに格納
され、オブジェクトノードの本来使われない数値フィールドで記述されます。おかげで参照
が線形走査に落ちることはありません。

## ここにあるもの

- `Value` — ハンドル。Python 風のコンテナ API を一式備えます。
- `ValueType` — 型タグ。対応する Python の型名として表示されます。
- `MAX_DEPTH` — すべての再帰的な走査が守るネスト上限。循環検出も兼ねます。値は
  ドキュメント内で互いを別名参照できるため、自身の部分木に差し込まれた値は、走査が
  終わらないことによってしか検出できません。
- JSON テキストライタ。JSON はこのモデルの正準的なテキスト形式であり、
  `Value.write_to` が必要とするためです。したがってどのフォーマットの値も同じ形で
  表示されます。

多くの利用者はこのパッケージを直接ではなく [`json`](../json) や [`yaml`](../yaml)
を通して使います。`json.JSONValue` と `json.JSONType` は `Value` と `ValueType`
の別名です。
